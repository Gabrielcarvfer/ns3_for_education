To properly visualize the demos, open the Jupyter notebooks via https://nbviewer.org/github/Gabrielcarvfer/ns3_for_education/tree/master/

To serve the notebooks locally, run from the repository root:

```bash
pip install jupyterlab
jupyter lab
```

Or, without installing anything permanently (requires [uv](https://docs.astral.sh/uv/)):

```bash
uvx --from jupyterlab jupyter-lab
```
